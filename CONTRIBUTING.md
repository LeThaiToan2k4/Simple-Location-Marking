# Contributing

Contributions, bug reports, and localization improvements for **Simple Location Marking** are welcome.

Before opening a pull request:

1. Use Java 21.
2. Run `./gradlew clean build` and verify that `build/libs/simplelocationmarking-fabric-1.21.11-1.0.0.jar` builds cleanly.
3. Keep the mod strictly client-side and fair-play (do not introduce teleportation or cheat mechanics).
4. Avoid per-frame object allocations in HUD rendering paths.
